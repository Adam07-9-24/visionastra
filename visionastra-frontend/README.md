# VisionAstra - Frontend

VisionAstra es una plataforma SaaS orientada a agencias de marketing digital que gestionan campañas, publicaciones, recursos multimedia y métricas para varios negocios clientes.

Este repositorio contiene el frontend del sistema, desarrollado con React, TypeScript y Vite.

## Descripción del proyecto

VisionAstra permite a una agencia de marketing digital organizar el trabajo de sus clientes desde una sola plataforma.

Por ejemplo, una agencia puede manejar campañas de una tienda de calzado, un restaurante, una barbería o una tienda de ropa. Desde VisionAstra podrá gestionar usuarios, sesiones activas, campañas, publicaciones, recursos visuales, calendario de contenido y métricas.
